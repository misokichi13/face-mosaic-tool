# face-mosaic-tool（顔モザイクツール）

写真・動画の顔を自動で検出してモザイクをかけるブラウザツールです。処理はすべてブラウザ内で行われ、画像や動画が外部に送信されることはありません。

公開URL: https://misokichi13.github.io/face-mosaic-tool/

## 使い方
1. AIモデルの読み込みが終わるまで待つ
2. 写真または動画ファイルを選ぶ
3. 顔には自動でモザイクがかかります。足りない所は画面タップで追加、外したい所は「モザイク解除」モードでタップ
4. 保存ボタンで保存（写真はJPEG、動画はWebM形式）

## 注意
- 顔検出にはMediaPipe Face Detection（CDN）を使っています
- 動画の保存形式はWebMです。再生・共有する環境によっては変換が必要な場合があります
- 大きな写真は保存時に長辺1920pxへ縮小されます
